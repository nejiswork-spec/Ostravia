# Social-card build font

Manrope.ttf is the Manrope variable TrueType font from the Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/manrope

It is licensed under the SIL Open Font License, retained at public/fonts/Manrope-OFL.txt.
Sharp's text renderer uses this build-only font for social cards. It is not copied into the
published directory. Browsers use the smaller self-hosted WOFF2 font instead.
